## 🛠️ Modern Tech Stack & Architecture

This application has been upgraded from static HTML/CSS to a high-performance modern React application:

* **Core Framework:** React 18 + Vite (ESM fast bundle engine)
* **Styling & Design System:** Tailwind CSS + PostCSS + Custom Cyberpunk Glow Utilities
* **3D Visuals & Canvas:** Three.js (Interactive WebGL Torus Knot & Starfield particle simulation)
* **Iconography:** Lucide React (Clean, tree-shakable modern vector icons)
* **Audio Feedback:** Native Web Audio API Synthesizer (Sci-fi chimes, click/hover tones with persistent mute toggle)
* **Terminal CLI & Contact:** Interactive terminal simulator + Formspree payload delivery
* **CI/CD Deployment:** GitHub Actions (`.github/workflows/deploy.yml`) for automated zero-config deployments to GitHub Pages

## 🌐 Deploying to GitHub Pages

When you push your commits to the `main` branch:
```bash
git add .
git commit -m "Upgrade site to React with modern UI/UX"
git push origin main
```

The GitHub Actions workflow (`.github/workflows/deploy.yml`) will automatically build the project and deploy it to **https://alistackdev.github.io/**.

> **Note on GitHub Pages Settings:**  
> In your GitHub repository settings under **Settings > Pages > Build and deployment**, ensure the **Source** is set to **GitHub Actions**.
